# JHipster v9.2.0 リリース

これはJHipster v9のマイナーリリースです。

[9.1.0リリース](/2026/05/27/jhipster-release-9.1.0.html)以降、[515件のクローズされたイシューとプルリクエスト](https://github.com/jhipster/generator-jhipster/issues?q=is:closed+milestone:9.2.0)が含まれています。

## 新機能

* 3000以上のEJSテンプレートが[eslintによってチェックおよびフォーマットされるようになりました](https://github.com/jhipster/generator-jhipster/issues/32851)
* [Spring Boot 4.0.7](https://github.com/jhipster/generator-jhipster/pull/33753)にアップグレードし、[より安全なAccountResource](https://github.com/jhipster/generator-jhipster/pull/33671)で生成されたバックエンドの強化を改善しました。
* [クライアントの選択肢からJestを削除](https://github.com/jhipster/generator-jhipster/pull/34017)し、[Angularの残存するJest条件をクリーンアップ](https://github.com/jhipster/generator-jhipster/pull/34006)することで、Vitestを生成されたアプリの唯一のフロントエンドテストフレームワークとしました。
* 初期プロジェクト生成のための[アプリケーション生成の修正](https://github.com/jhipster/generator-jhipster/pull/33507)が含まれました。
* [自動生成IDを持たないエンティティのPUTサポート](https://github.com/jhipster/generator-jhipster/pull/34013)、[Reactエンティティ作成の修正](https://github.com/jhipster/generator-jhipster/pull/34029)、および[VueのBooleanフィールドレンダリングの修正](https://github.com/jhipster/generator-jhipster/pull/33759)により、Angular、React、Vue全体で生成されたフロントエンドの動作を修正しました。
* [より強力なgenerate-blueprintの型付けと互換性](https://github.com/jhipster/generator-jhipster/pull/33927)、[再構築されたブートストラップジェネレーターの構成](https://github.com/jhipster/generator-jhipster/pull/33688)、および[MemFsEditorFileの統合](https://github.com/jhipster/generator-jhipster/pull/33922)により、ブループリントの生成と内部を改善しました。
* ビルドツールを[Node 24.18.0](https://github.com/jhipster/generator-jhipster/pull/33880)、[Gradle 9.6.1](https://github.com/jhipster/generator-jhipster/pull/33915)、および[webpack-dev-server 6](https://github.com/jhipster/generator-jhipster/pull/34007)にアップグレードしました。

## インストール方法

NPMを使用してJHipster v9.2.0をインストールするには：

```
npm install -g generator-jhipster@9.2.0
```

JHipster Dockerイメージを使用しても利用可能です。これはソースコードから自動的にビルドされます。

- [Docker Hub](https://hub.docker.com/r/jhipster/jhipster)
- [JHipster Online](https://start.jhipster.tech)

## アップグレード方法

**自動アップグレード**

自動アップグレードには、既存のアプリケーションで[JHipsterアップグレードサブジェネレーター](/upgrading-an-application/)を使用します。

JHipsterのバージョンをアップグレードします。

```
npm update -g generator-jhipster
```

そして、アップグレードサブジェネレーターを実行します。

```
jhipster upgrade
```

より高度なアップグレード機能には、[migrateブループリント](https://github.com/jhipster/generator-jhipster-migrate)も使用できます。

```
npm i -g generator-jhipster-migrate
jhipster-migrate
```

**手動アップグレード**

手動アップグレードの場合、まずJHipsterのバージョンを以下でアップグレードします。

```
npm update -g generator-jhipster
```

既存のプロジェクトがある場合、それは生成されたJHipsterのバージョンを使い続けます。
プロジェクトをアップグレードするには、まず`node_modules`フォルダを削除し、その後以下を実行する必要があります。

```
jhipster
```

また、以下を実行することで、プロジェクトとそのすべてのエンティティを更新できます。

```
jhipster --with-entities
```

エンティティサブジェネレーターを再度実行することで、エンティティを1つずつ更新することもできます。例えば、エンティティ名が_Foo_の場合：

```
jhipster entity Foo --single-entity
```
